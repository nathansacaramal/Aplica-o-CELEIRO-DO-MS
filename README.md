# Aplicação Celeiro do MS

Catálogo público de eventos, pontos turísticos e conteúdo institucional da região do Celeiro do MS, com painel administrativo (CMS) para gestão de conteúdo.

Este repositório reúne os dois projetos que compõem a aplicação:

- [`front-end/`](./front-end) — Portal público e painel admin (React + TypeScript + Vite).
- [`api/`](./api) — Backend/BFF (Node.js + Express + Sequelize/MySQL) que serve os dados consumidos pelo front-end.

Cada projeto tem seu próprio `README.md` com instruções de instalação, configuração de ambiente e deploy.
